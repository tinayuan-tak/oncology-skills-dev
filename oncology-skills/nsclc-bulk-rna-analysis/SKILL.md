# NSCLC Bulk RNA-seq Analysis & Target Evaluation

## Overview

Analyze gene expression across non-small cell lung cancer (NSCLC) cohorts, normal tissue comparisons, molecular subtypes, and lung cancer cell lines. Generates comprehensive target evaluation reports.
