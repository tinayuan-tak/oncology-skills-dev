# CRC Gene Expression Analysis & Target Evaluation

## Overview

Analyze gene expression across colorectal cancer (CRC) cohorts, normal tissue comparisons, CMS subtypes, and CRC cell lines. Generates comprehensive target evaluation reports with publication-ready figures.

## Key Capabilities

- **Cohort Comparisons**: 2A (RAS-mut MSS), 2B (RAS-WT MSS), 4 (Early Stage), 5 (All MSS), 6 (MSI-H)
- **CMS Subtype Analysis**: CMS1-4 stratification with statistical comparisons
- **Normal Tissue Comparisons**: TCGA Adjacent Normal, GTEx Normal Colon
- **Target Evaluation Reports**: Comprehensive markdown reports with figures and statistics

## Data Sources

### Expression Data (Omicsoft Reprocessed)
- **Path**: User-specified or default location
- **Format**: log2(TPM+0.001) transformed, gene rows x sample columns

### Required Input Files
| File | Description |
|------|-------------|
| `cohort_assignments.csv` | Pre-computed cohort memberships (2A, 2B, 4, 5, 6) |
| `TCGA_CMS_prediction.csv` | CMS subtype predictions (download from S3) |
| `TCGA-COAD-READ-AdjNormal.tsv` | TCGA adjacent normal sample IDs |
| `GTEx_Analysis_v10_Annotations_SampleAttributesDS.txt` | GTEx tissue annotations |

### S3 Data
```bash
# Download CMS predictions
aws s3 cp s3://onc-compbio/TCGA/TCGA_CMS_prediction.csv ./ --profile cbg
```

## CRC Cohort Definitions

| Cohort | Definition | Description |
|--------|------------|-------------|
| **2A** | RAS-mutant MSS | Frontline RAS-mutant, microsatellite stable |
| **2B** | RAS-WT MSS | Frontline RAS wild-type, microsatellite stable |
| **4** | Early Stage | Stage I/II CRC |
| **5** | All MSS | All microsatellite stable samples |
| **6** | All MSI-H | All microsatellite instability-high samples |

## CMS Subtypes

- **CMS1**: MSI Immune
- **CMS2**: Canonical
- **CMS3**: Metabolic
- **CMS4**: Mesenchymal

def assign_cohorts(metadata):
    """Assign samples to CRC cohorts based on MSI status, RAS status, and stage."""
    cohorts = {}

    for idx, row in metadata.iterrows():
        sample_id = row['sample_id']
        msi_status = str(row.get('msi_status', '')).upper()
        ras_status = str(row.get('ras_status', '')).upper()
        stage = str(row.get('ajcc_pathologic_stage', '')).upper()

        sample_cohorts = []

        # MSI-H vs MSS classification
        is_msi = 'MSI' in msi_status and 'MSS' not in msi_status
        is_mss = 'MSS' in msi_status or 'STABLE' in msi_status

        # RAS classification
        is_ras_mut = 'MUT' in ras_status or 'POSITIVE' in ras_status
        is_ras_wt = 'WT' in ras_status or 'WILD' in ras_status or 'NEGATIVE' in ras_status

        # Stage classification
        is_early = 'I ' in stage or 'II' in stage or stage in ['STAGE I', 'STAGE IA', 'STAGE IB', 'STAGE II', 'STAGE IIA', 'STAGE IIB', 'STAGE IIC']

        # Assign cohorts
        if is_mss and is_ras_mut:
            sample_cohorts.append('Cohort_2A')
        if is_mss and is_ras_wt:
            sample_cohorts.append('Cohort_2B')
        if is_early:
            sample_cohorts.append('Cohort_4')
        if is_mss:
            sample_cohorts.append('Cohort_5')
        if is_msi:
            sample_cohorts.append('Cohort_6')

        cohorts[sample_id] = sample_cohorts

    return cohorts

def extract_gene_expression(expression_df, gene_id, sample_ids):
    """Extract expression values for a gene across samples."""
    if gene_id not in expression_df['gene_id'].values:
        return None

    gene_row = expression_df[expression_df['gene_id'] == gene_id].iloc[0]

    expr_values = {}
    for col in expression_df.columns:
        if col in sample_ids:
            expr_values[col] = gene_row[col]

    return expr_values

def calculate_statistics(groups_dict):
    """Calculate descriptive statistics and comparisons."""
    stats_records = []

    for group_name, values in groups_dict.items():
        values = np.array([v for v in values if not np.isnan(v)])
        if len(values) > 0:
            stats_records.append({
                'group': group_name,
                'n': len(values),
                'mean': np.mean(values),
                'median': np.median(values),
                'std': np.std(values),
                'min': np.min(values),
                'max': np.max(values),
                'q25': np.percentile(values, 25),
                'q75': np.percentile(values, 75)
            })

    return pd.DataFrame(stats_records)

def perform_pairwise_comparisons(groups_dict, reference_groups=['TCGA_Adjacent', 'GTEx_Normal']):
    """Perform pairwise Mann-Whitney U tests."""
    results = []

    for ref_group in reference_groups:
        if ref_group not in groups_dict:
            continue
        ref_values = np.array([v for v in groups_dict[ref_group] if not np.isnan(v)])
        if len(ref_values) == 0:
            continue

        for group_name, values in groups_dict.items():
            if group_name in reference_groups:
                continue
            values = np.array([v for v in values if not np.isnan(v)])
            if len(values) == 0:
                continue

            stat, pval = mannwhitneyu(values, ref_values, alternative='two-sided')
            log2fc = np.median(values) - np.median(ref_values)

            results.append({
                'comparison_group': group_name,
                'reference_group': ref_group,
                'n_comparison': len(values),
                'n_reference': len(ref_values),
                'median_comparison': np.median(values),
                'median_reference': np.median(ref_values),
                'log2fc': log2fc,
                'u_statistic': stat,
                'p_value': pval
            })

    df = pd.DataFrame(results)
    if len(df) > 0:
        _, pvals_adj, _, _ = multipletests(df['p_value'], method='fdr_bh')
        df['p_adjusted'] = pvals_adj
        df['significant'] = df['p_adjusted'] < 0.05

    return df

        median.set_color('black')
